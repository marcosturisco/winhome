## Instalar ou atualizar
1. Baixe **WinHome-{versao}.zip** (abaixo, em *Assets*).
2. Botão direito → **Extrair tudo**.
3. Duplo clique em **`instalar.cmd`**. Numa instalação existente, ele atualiza por cima e **mantém a sua configuração**.

Não precisa de administrador; .NET e Windows App SDK já vão dentro. Se aparecer "O Windows protegeu o computador":
**Mais informações → Executar assim mesmo** (o programa não é assinado). Para remover: `desinstalar.cmd`.
